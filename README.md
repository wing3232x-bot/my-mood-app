# 気分記録アプリ（Supabase版）

このアプリは、今の気分を1〜5段階で選択し、一言メモとともに記録できるWebアプリです。  
記録したデータは Supabase のデータベースに保存されるため、アプリを終了しても消えず、後から振り返ることができます。

## 主な機能
- 気分を1〜5段階で記録
- 一言メモの入力
- 過去の記録を一覧で表示
- Supabaseを利用したデータの永続保存

## 使用技術
- Streamlit
- Supabase（PostgreSQL）
- Python
